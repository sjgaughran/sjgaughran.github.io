# Gaughran Lab website

Public site: https://sjgaughran.github.io/

GitHub Pages serves the repository root on `master`. The website uses static HTML and CSS with no build step.

- `index.html`: Home
- `research.html`: Research
- `team.html`: Team and CV download
- `publications.html`: Publications
- `styles.css`: Shared styling
- `assets/`: Photos and CV
- `publications-data.json`: Bibliography metadata

To review changes locally, run `python3 -m http.server 8000` from the repository root and open http://localhost:8000/.

Hosted review preview: https://gaughran-lab-draft-preview.stephengaughran.chatgpt.site/
The preview is a separate copy; refresh it alongside future source changes before launch.
